# Invention Disclosure 2 — Self-Tuning Phase-Locked Hydraulic Ram (+ Bank Coordination)
**Date of record:** 2026-07-19 · **Inventor:** NATRIX · **Status:** internal draft; clock-sensitive (competitor CN116802400A pending, priority 2020-12).
**Title:** Hydraulic ram with per-cycle closed-loop valve control targeting the zero-recoil condition, and phase-coordinated operation of ram banks.
**The invention:** (a) a ram whose waste-valve preload/timing is servo-controlled per cycle from a single pressure/flow sensor using a SWEEP-THEN-TRACK law (commissioning sweep maps the multi-modal recoil landscape, controller holds the global minimum — the water-efficiency knee — with best-point memory and drift re-sweep); (b) deliberate anti-synchronization of N rams on a shared manifold (stagger 1/N of cycle period) reducing headstock inflow ripple ~90%, shared-pipe loss ~80%, and peak intake draw ~35%; (c) control objective switchable between water-delivery and generation-optimized targets.
**Reduction to practice:** `servo_min_recoil.py` v3 (+29–42% vs drifted fixed valve, mistune + seasonal-drift scenario), recoil instrumentation in `ram_moc_sim.py`, `bank_phase_model.py` quantification. Failure record (v1 chatter-basin, v2 real second attractor) documents non-obviousness of the working law.
**Prior art distinguished:** CN116802400A (HydroHammer) claims stepper aperture restriction + remote start/stop + EM opening assist — NOT cycle-timing control, NOT phase-locking, NOT bank coordination, NOT generation-target control (searches on record, COMPONENT_TECH_SCAN/RAM_RESONANCE_RESEARCH). Young 1995/96 published zero-recoil as a design-time calculation, not a control target. CN212675388U (expired) = monitoring only.
**Claims outline:** (1) per-cycle valve-event sensing + debounced recoil metric; (2) sweep-then-track extremum control with commissioning map + memory; (3) N-ram stagger control; (4) generation-mode objective; (5) single-sensor stall detection (recoil >1 threshold).
