# Decision D-6 — Fluting Intent Ratified as Flow Conditioning; Honeycomb Arm Added

**Date:** 2026-07-18 · **Authority:** Founder (NATRIX) · **Status:** RATIFIED
**Founder statement:** "intent behind fluting is flow conditioning, the literature-backed equivalent is a honeycomb straightener at the manifold — that option's on the table too."

## What is decided

1. **The design intent of the fluted penstock is formally recorded as FLOW CONDITIONING** — delivering a clean, low-swirl, low-turbulence feed to the twin nozzles — not friction reduction. All docs describing fluting inherit this intent statement.
2. **The honeycomb flow straightener at the manifold is adopted as a test arm** — the literature-backed route to the same intent (straightener science is measured in aero/metrology; its application immediately upstream of a micro impulse nozzle is unpublished — novel data either way).
3. **The fluted penstock is NOT removed** (no-silent-substitution rule). It goes to a fair, instrumented comparison against its intent.

## The bench comparison this fires (digital first, physical when the rig exists)

Three arms, identical site and flow, judged on the metric that matches the intent:

| Arm | Config | Predicted by literature |
|---|---|---|
| A (baseline) | smooth penstock, plain manifold | reference |
| B (founder) | fluted penstock | friction +1.6–2.7× (measured, mm-scale ribs); swirl effect on jet unknown — unpublished |
| C (literature) | smooth penstock + honeycomb straightener at manifold (≥3×D straight run to nozzle) | conditioning gain, small pressure drop — unpublished at micro-nozzle scale |

**Primary metric: jet CoV (T-001)** — the intent is jet quality, so jet quality decides. Secondary: net head loss, electric output, T-002 coherence. Success for any arm = better CoV without losing more head than the jet gain repays in efficiency (>2-point efficiency stake per Staubli-line jet-quality data).

## Consequences

- Bench A/B roster updated: the "fluting" slot becomes the three-arm conditioning comparison above; the honeycomb arm is added to the digital-bench queue (jet/manifold model — after sim queue #1–3, which gate everything).
- If B loses on CoV *and* friction, the founder decides disposition with the data in hand — this decision pre-authorizes nothing beyond the test.
- If C wins, the honeycomb straightener + straight-run manifold becomes the conditioning spec and fluting is retired **by measurement, not by argument** — the way every founder element decision is supposed to go.
- Either B or C winning on CoV produces publishable/IP-relevant data (both configurations unpublished at this scale).
