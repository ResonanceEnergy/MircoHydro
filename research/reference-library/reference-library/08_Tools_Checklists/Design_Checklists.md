# Off-grid system design checklists

## A) Requirements
- [ ] Daily energy (kWh/day) estimated
- [ ] Peak load (kW) + surge loads identified
- [ ] Reliability target (autonomy days, critical loads) defined

## B) Generation
- [ ] Solar resource (monthly) reviewed
- [ ] Wind resource (hub-height, turbulence) assessed (if applicable)
- [ ] Hydro head/flow measured + seasonal variability assessed (if applicable)
- [ ] Bioenergy feedstock availability quantified (if applicable)

## C) Storage & power electronics
- [ ] Battery chemistry selected (temperature, cycle life, safety)
- [ ] Inverter surge rating adequate
- [ ] Charge controller(s) sized with cold-weather Voc margin

## D) Safety
- [ ] Disconnects & overcurrent protection specified
- [ ] Grounding/bonding plan documented
- [ ] Proper enclosures, cable sizing, strain relief, fusing
- [ ] Fire safety plan for batteries

## E) Operations
- [ ] Monitoring/telemetry plan
- [ ] Spare parts plan
- [ ] Seasonal operating procedures
